# 🚀 T Santhosh Kumar - Software Engineer Portfolio

A premium, production-grade personal portfolio website engineered with **Next.js (App Router), React, TypeScript, Tailwind CSS, and Lucide Icons**.

---

## 🎯 Positioning & Identity

- **Primary Positioning**: Software Engineer
- **Secondary Positioning**: Backend Engineer • Python Full Stack Developer • AI/GenAI Engineer
- **Design Language**: Linear / Vercel / GitHub inspired technical aesthetic with dark-first palette (`#080B10`), subtle cyan & violet accents, and interactive architecture visualizers.

---

## ⚡ Tech Stack

- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Typography**: Space Grotesk (Headings), Inter (Body), JetBrains Mono (Technical Labels)
- **Icons**: Lucide React & Custom Pixel-Perfect Social SVGs
- **Interactivity**: Interactive Software Architecture Visualizer, Two-Sum Algorithm Walkthrough, System Design Topology Inspector

---

## 📂 Component Architecture

```
src/
├── app/
│   ├── globals.css               # Linear-inspired cards & grid styles
│   ├── layout.tsx                # Open Graph, SEO, and font preconnections
│   └── page.tsx                  # Clean hierarchical composition
├── components/
│   ├── Navbar.tsx                # Sticky blur navbar with 'Open to Work' indicator
│   ├── Hero.tsx                  # Software Engineer headline & core stack
│   ├── ArchitectureVisualization.tsx # Interactive animated system data flow
│   ├── About.tsx                 # Concise positioning & 3 core competence cards
│   ├── EngineeringPhilosophy.tsx # Design, Build, Optimize, Ship principles
│   ├── Experience.tsx            # Vertical timeline for Unishrine & 3 Fortune Minds
│   ├── Projects.tsx              # Engineering case studies with pipeline visualizers
│   ├── ProjectModal.tsx          # Expanded architectural deep-dive drawer
│   ├── SystemArchitecture.tsx    # "How I Build Systems" interactive node inspector
│   ├── Skills.tsx                # Categorized technology groups (NO percentage bars)
│   ├── EngineeringPractice.tsx   # DSA topics & interactive Two Sum algorithm walk
│   ├── GithubSection.tsx         # Open source repositories & profile showcase
│   ├── Contact.tsx               # Professional contact, copy buttons & message form
│   ├── Footer.tsx                # Positioning, profiles & back-to-top
│   ├── GlobalBackground.tsx      # Subtle engineering grid with moving light beam
│   └── SocialIcons.tsx           # LinkedIn, GitHub, LeetCode, Naukri SVGs
├── data/
│   └── portfolioData.ts          # Central typed repository of all portfolio data
└── lib/
    └── utils.ts                  # Classname merging helper
```

## 🚀 Production Build & Deployment

```bash

# Start production server
npm run start
```
